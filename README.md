## Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/YOUR-USERNAME/smartbiz-ai.git
   cd smartbiz-ai
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file (see `.env.example`) and add your key
   ```
   ANTHROPIC_API_KEY=your_key_here
   ```
4. Run the app
   ```bash
   python main.py
   ```
